# Exploring the Graph View

One of the most powerful features of Blog Engine MD is the **graph view**. It visualizes connections between all your pages.

## How It Works

The graph view analyzes:

1. **Wiki Links**: Connections made with `[[Page Title]]` syntax
2. **Regular Links**: Standard markdown links between pages
3. **Tags**: Pages sharing common tags

## Visualizing Your Content

The graph shows:
- **Nodes** as circles (size based on link count)
- **Edges** as lines connecting related pages
- **Colors** based on content type (blog, docs, etc.)

## Interactive Features

- Click nodes to navigate
- Drag to rearrange
- Zoom and pan
- Filter by content type
