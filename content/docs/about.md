# About Blog Engine MD

Blog Engine MD is a high-performance static site generator written in Go.

## Philosophy

- **Fast builds**: Leverages Go's concurrency for quick site generation
- **Low memory**: Efficient memory usage even for large sites
- **Simple**: Markdown-based content with YAML frontmatter
- **Flexible**: Customizable templates and layouts
