# Getting Started

Welcome to Blog Engine MD! This guide will help you get started with building your static site.

## Features

Blog Engine MD supports many powerful features:

- **Wiki-style Links**: Link to other pages with double bracket syntax like `[[Getting Started]]`
- **Images**: Embed images with standard markdown
- **Code Highlighting**: Syntax highlighting for code blocks
- **Graph View**: Visualize connections between pages

## Wiki Links

You can link to other pages using wiki-style syntax:

- Link to [[About]] page
- Link to [[My First Post|the first blog post]]
- Link to [[Getting Started|this page]]
